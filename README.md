# Trombinoscope pour [DOLIBARR ERP & CRM](https://www.dolibarr.org)

## Caractéristiques
Module affichant un trombinoscope de votre structure à partir des photos déjà enregistrées dans Dolibarr :
- Personnes affichées au choix : utilisateurs internes actifs ou adhérents validés, avec filtres par groupe d'utilisateurs ou par type d'adhérent
- Photo de la fiche utilisateur ou de la fiche adhérent : si l'une manque, l'autre est utilisée
- Informations affichées au choix : e-mail, téléphones, ville, fonction, type d'adhérent et tous les champs complémentaires des utilisateurs et des adhérents
- Mise en avant des nouveaux arrivants avec des couleurs personnalisables
- Recherche instantanée dans la page
- Widget « Nouveaux arrivants » pour la page d'accueil
- Photos servies par Dolibarr lui-même, en vignettes et avec cache du navigateur : affichage rapide même avec plusieurs centaines de personnes
- S'intègre automatiquement au menu du module Intranet s'il est installé, sinon dispose de son propre menu

## Installation
Vous pouvez copier ces fichiers directement dans le dossier custom/trombinoscope de votre Dolibarr. Vous pouvez également télécharger la dernière release disponible sur Dolistore.

Activez ensuite le module, donnez le droit « Voir le trombinoscope » aux utilisateurs ou groupes concernés, puis réglez le module depuis sa page de configuration.

## Statistiques d'utilisation
À l'activation du module, une requête anonyme est envoyée à disqutons.fr avec le nom et la version du module, la version de Dolibarr et une empreinte non réversible de l'instance. Elle nous permet seulement de savoir combien d'instances utilisent le module.

## Traductions/Translations
Le module est disponible en français, anglais, allemand, italien et espagnol. Les traductions peuvent être complétées manuellement en éditant les fichiers du répertoire `langs`.
The module is available in French, English, German, Italian and Spanish. Translations can be completed manually by editing files in the `langs` directory.
